# tokens-per-dollar

**What your own last 30 days of Claude Code and Codex would cost on every coding plan.**

```sh
npx --allow-git=root github:agentwares/tokens-per-dollar
```

![tokens-per-dollar on synthetic history](https://raw.githubusercontent.com/agentwares/tokens-per-dollar/main/docs/screenshot.svg)

<sub>The picture is the real output of `npx --allow-git=root github:agentwares/tokens-per-dollar demo`, which runs on
synthetic history generated for the demo, not anyone's usage. It is regenerated by
`pnpm screenshot`, and a test fails if it drifts from what the CLI prints.</sub>

Pricing pages and calculators tell you what a plan costs. This tells you what **your** month costs
on each of them. It reads the transcripts Claude Code and Codex already keep on your machine, takes
the token counts, and prices them on:

| Plan                               | Price a month (billed monthly)                | How your month is priced                                                 |
| ---------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------ |
| Anthropic API, OpenAI API          | pay as you go                                 | every token at list price                                                |
| Claude Pro, Max 5x, Max 20x        | $20, $100, $200                               | the fee, and the condition under which it alone carries your month ¹     |
| Claude Team standard, Team premium | $25, $125 a seat (at least 2 seats)           | the same ¹                                                               |
| ChatGPT Plus, Pro                  | $20; Pro tiers at $100, $200 and $500         | **measured** from Codex's own limit readings, for the plan you were on ² |
| Codex credits                      | pay as you go                                 | OpenAI's per-token credit rate card, at $0.04 a credit (derived) ³       |
| Copilot Pro, Pro+, Max             | $10, $39, $100 ($15, $70, $200 of AI credits) | GitHub's per-token rates for the same tokens: **an estimate** ⁴          |

It prints the cheapest priced plan for each client, the margin against the cheapest plan from
another vendor, the plans that could be cheaper and on what condition, and **the date of the last
vendor change that moved the answer**: the newest dated change that, undone, would change it.

¹ Anthropic publishes Claude plan allowances only as multiples of Pro per 5-hour session (Max 5x is
5×, Max 20x 20×, Team standard 1.25×, Team premium 6.25×), plus a weekly limit, and no token or
dollar figure for any of them. Past the allowance, extra usage is billed at API rates. So
tokens-per-dollar never invents one: it shows the fee as "from", and your busiest 5 hours and busiest
week at API prices, which is what the allowance would have to hold for the fee alone to carry your
month. On Pro and Team standard, Fable models run on usage credits only, so they are added at API
rates from the first token.\
² Codex writes its own 5-hour and weekly percentages, and the plan, into its session files. When
they show the plan you were on never reached 100%, its fee carried your month: that is measured, not
estimated. OpenAI publishes no allowance for a plan you were not on (Pro has no 5-hour limit and no
published multiple of Plus), so those get the fee and a condition.\
³ OpenAI does not state a price per credit for Plus or Pro. $0.04 is derived from its own figures:
"$100 worth of workspace credits (2,500 credits)", and its Enterprise USD rate card, which is 25
credits to the dollar on every row. At $0.04, each model on the credit card that tokens-per-dollar
prices comes to its API list price for input, cached input and output; a test holds it. Credits
have no separate cache-write charge.\
⁴ Copilot keeps no local logs, and its agent would not use exactly these tokens, so the Copilot rows
are your Claude Code and Codex tokens at GitHub's per-token rates (1 AI credit = $0.01), less the
credits each plan includes. Included credits contain a flex allotment GitHub says may change.

Every metered figure is stated for a 30-day month. Plan prices, their sources and the date each was
read are in one table, `plans.ts` in [seatledger](https://github.com/agentwares/seatledger), and
`--json` prints them with the answer.

## Options

```sh
npx --allow-git=root github:agentwares/tokens-per-dollar                         # the last 30 days, every plan
npx --allow-git=root github:agentwares/tokens-per-dollar --since 2026-09-14      # a range (or 90d, 12w); still stated per 30 days
npx --allow-git=root github:agentwares/tokens-per-dollar --plans claude,copilot  # only some plans: ids or groups (claude, codex, copilot)
npx --allow-git=root github:agentwares/tokens-per-dollar --json                  # the whole answer, every source and date
npx --allow-git=root github:agentwares/tokens-per-dollar demo                    # the same on synthetic history
```

Also `--claude-dir`, `--codex-dir`, `--no-cache` and `--quiet`. Plan ids: `anthropic-api`,
`claude-pro`, `claude-max-5x`, `claude-max-20x`, `claude-team-standard`, `claude-team-premium`,
`openai-api`, `chatgpt-plus`, `chatgpt-pro`, `codex-credits`, `copilot-pro`, `copilot-pro-plus`,
`copilot-max`.

## What it reads, and what it sends

- **Reads** token counts, model ids, timestamps and Codex's rate-limit readings from Claude Code's
  transcripts (`~/.claude/projects`, or `$CLAUDE_CONFIG_DIR/projects`) and Codex's rollouts
  (`~/.codex/sessions`, or `$CODEX_HOME/sessions`), through the readers of
  [seatledger](https://github.com/agentwares/seatledger), its one dependency.
- **Keeps** counts per transcript, never text, in `~/.tokens-per-dollar` (`--no-cache` to skip).
- **Prints** counts, dollars, plan names and dates. Never prompt or response text, file paths or
  project names, so the output can be pasted anywhere.
- **Sends nothing.** No network request, no telemetry, no account, no LLM call.

What it cannot see: use on other machines, and Claude on the web and desktop, which shares a Claude
plan's allowance. Codex's readings are account-wide, so they do include other machines.

## From your agent

The same answer is the `seatledger_plan_compare` tool on seatledger's read-only MCP server:

```sh
claude mcp add seatledger -- npx -y seatledger mcp
```

In Claude Code, the plugin runs the CLI and explains the answer:

```text
/plugin marketplace add agentwares/tokens-per-dollar
/plugin install tokens-per-dollar@tokens-per-dollar
/tokens-per-dollar:plans
```

## Vendor changes it knows about

The answer moves when these do. Each is dated as the vendor dates it; "reported" means the press
quoting the vendor, because the vendor's own post could not be read.

| Date        | Vendor    | Change                                                                                                   |
| ----------- | --------- | -------------------------------------------------------------------------------------------------------- |
| 16 Jan 2026 | Anthropic | Claude Code access added to Team standard seats                                                          |
| 2 Apr 2026  | OpenAI    | Codex credits priced by token, aligned with API token usage, instead of per message                      |
| 13 May 2026 | Anthropic | Weekly limits in Claude Code 50% higher, as a promotion through 13 September                             |
| 1 Jun 2026  | GitHub    | Every Copilot plan billed in AI credits, each token priced by model, replacing premium requests          |
| 25 Aug 2026 | OpenAI    | Five-hour limit back on Codex for Plus (reported); Pro without one                                       |
| 14 Sep 2026 | Anthropic | Promotion ended: weekly limits 25% above their pre-promotion level, one sixth (about 17%) below August's |
| 7 Oct 2026  | Anthropic | Max and Team include monthly API credits for the Claude Platform, not for interactive Claude Code        |
| 14 Oct 2026 | OpenAI    | GPT-5.5 retires from Codex on all plans (announced)                                                      |

## For a team

Your month on one machine is one row. [seatledger](https://agentwares-agentcheck.vercel.app/seatledger?ref=tokens-per-dollar)
keeps the whole team's coding-agent ledger and flags when the token rate moves: free for up to 3
developers; email alerts on Team, $49 a month.
